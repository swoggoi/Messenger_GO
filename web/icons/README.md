# Иконки

SVG-иконки скачаны с [Lucide Static](https://github.com/lucide-icons/lucide) версии `0.468.0`
через CDN `cdn.jsdelivr.net/npm/lucide-static@0.468.0/icons/`.

Лицензия: ISC (см. комментарий `@license` в начале каждого SVG-файла).

Использование в интерфейсе: CSS-маски (`.ico`, `.ico-<name>` в `web/style.css`),
поэтому цвет иконки наследуется от текста и не зависит от темы.
